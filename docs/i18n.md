# i18n 首批实现

这是基础设施与贯通样板，仍是部分翻译。中文缺 key 时回退英文，未迁移内容保留英文；不需要完整语言包才能运行游戏。

## 已接入

- `intl-messageformat` ICU 消息服务；英文、简体中文随构建打包，切换无需网络。
- 视觉选项页语言选择、应用级 `ade.language` 偏好、文档 lang/dir、切换通知。
- 游戏速度、选项 tab/subtab 名称、默认 ON/OFF、普通与大数记数法标签。
- 一个 Infinity 升级的普通/充能动态描述，以及少量倍率状态说明。
- `TextRef` 与旧字符串/函数兼容的 `DescriptionDisplay`，包括暂停时刷新缓存和既有 scramble 效果。
- 加速器、炼金精炼记录、Ethereal 星体、自动机模板、tab 动画与经典 tab 样式的标识解耦。

## 开发约定

1. Vue 使用 `$t(key, values)`，核心显示代码显式导入 `t`。不要在模块加载时将 `t()` 的结果永久存入配置。
2. 配置描述可以使用 `textRef(key, values)`，动态参数用函数。`resolveText` 兼容旧字符串和函数；数值 effect 保持原有数据类型。
3. 先 `format` / `formatX` / `formatInt` 等，再将大数结果作为字符串传入消息。服务拒绝 Decimal、其他对象、Infinity、NaN 和不安全的原生整数。
4. `name`、保存键、语法、CSS、新闻和剧情 ID、用户自定义名称不能因翻译改变。显示使用单独入口；先查全部消费者，再迁移该领域。
5. 中文尚未确认的消息可省略，让服务回退英文。新增 key 先提供英文基础消息；已有中文必须与英文参数和 select 分支一致。复数类别允许按语言不同。
6. 首批 `t` / `TextRef` 仅输出纯文本，使用 Vue 文本绑定；富文本入口在后续迁移中单独建设，不将译文直接交给 `v-html`。
7. 语言偏好不写进 `player`，跨存档槽保持当前语言。失败的持久化和损坏的候选包不会阻止有效文本或游戏运行。

## 检查

```sh
npm run i18n:check
npm run i18n:audit
npm run test:i18n
node scripts/i18n-audit.cjs --json > identity-candidates.json
```

`i18n:check` 检查重复 key、ICU 语法、已有译文参数、英文基础消息引用，以及指定模板的新硬编码文字；报告已提取消息的中文覆盖与英文回退数。这不是全游戏完成率。

`i18n:audit` 扫描名称比较、名称分派、名称派生索引和字符串查找候选。它不能证明已经覆盖所有动态依赖，也不自动修改源码。结合 [标识清单](i18n-identities.json) 追踪定义、消费、写入与旧存档兼容，再做实际行为验证。

全量旧测试已有失败，首批 CI 运行新增 i18n 测试、已有 Pelle Domain 回归与构建；全量测试另外比较失败集合，不能将既有失败忽略后宣称全部通过。

本批验证记录（2026-10-03）：

- `test:i18n`：23 项通过；全量 `node --test tests/*.test.cjs`：410 项，362 通过、48 失败，失败名称集合与改动前一致。
- 消息检查通过：英文 72 条、中文 71 条、1 条明确回退英文；迁移范围外的英文未计入覆盖率。
- 已修改源码的 lint 没有新增诊断，新服务、语言组件和构建配置通过 lint；master 模式构建通过。
- Chromium 133 实际页面验证了现代/经典界面暂停时切换、语言偏好刷新恢复、英文回退、动态升级描述，以及切换前后存档内容一致。
- 原问题存档验证了未能购买 AD9 时继续生产、达到条件后暂停、购买、结局重载、生产恢复、跨存档标志清理与新 Domain 进入；无浏览器异常。

`intl-messageformat` 通过 `transpileDependencies` 交给现有 Babel：仓库的 Webpack 5.64 无法正确处理该库原始 class static block 中的导入引用。新增消息依赖时必须同时验证真实构建页面的启动，不能只看构建退出码。

后续按 [范围清单](i18n-scope.json) 迁移主进度、ADE 系统、自动机反馈、帮助、新闻与剧情。新增领域必须补标识审计和消息 key；完整支持需最终盘点启动页面、资源文字和无障碍属性。

术语与来源见 [术语表](i18n-glossary.md)。首批未新增异步语言包加载；后续若引入分包，应补请求竞态与离线缓存测试。
