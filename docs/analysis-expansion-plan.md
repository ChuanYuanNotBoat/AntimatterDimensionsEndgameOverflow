# 乘数分析页扩展计划

日期：2026-10-07

状态：已于 2026-10-08 实现以下新增分析页；验收记录见 `analysis-expansion-implementation.md`。

## 1. 页面与显示条件

沿用现有乘数分析的分类、展开条目、倍率与指数切换，不新增顶层游戏页面。

| 分析对象 | 位置与切换方式 | 显示条件 | 主要结果 |
| --- | --- | --- | --- |
| 天界维度 | 维度分类，整体与单层切换 | 与天界维度页面一致：`PlayerProgress.endgameUnlocked()`；单层仅列出已解锁维度 | 每层倍率、指数、限制与最终结果 |
| 神性维度 | 维度分类，整体与单层切换 | 与神性维度页面一致：`DivinityMilestone.divineDimensions.isReached`；单层遵循实际购买与解锁规则 | 每层倍率、指数、限制与最终结果 |
| 机器 | 重置分类，一个页面内切换现实／虚幻／重构机器 | 现实机器沿用现实进度；虚幻与重构机器沿用对应游戏页面的解锁条件 | 现实机器奖励；虚幻／重构机器容量及限制 |
| 现实次数 | 重置分类 | 与现实进度一致 | 本次现实增加的次数及其来源 |
| 终局次数 | 重置分类 | 与终局进度一致 | 本次终局增加的次数及其来源 |

当前语言包中，Dual Machines 的中文名称是“重构机器”；后续延用这一名称。

现有导航编号 0–11 属于存档数据，保持不变。新增资源使用后续编号；机器内部切换不占用三个顶层入口。页面暂时不可见时，沿用当前导航的有效页面回退规则。

地狱中的切换规则继续保持本阶段约定：使用现有“切换页面”按钮，只开放 AD 乘数分析正文。

## 2. 天界维度与神性维度

- 从实际维度计算中提取来源与步骤，按游戏原有顺序记录乘法、幂运算和上下限，避免独立复制一套公式。
- 整体视图只汇总正在产生作用的层级，并明确汇总的是维度倍率。生产量另列为带单位的结果。
- 单层视图显示基础倍率、升级与成就、天神与特殊状态、指数、最终限制。
- 覆盖 Slabdrill 覆盖公式、禁用现实后效果等分支；不适用的来源不伪装成有效增益。
- 沿用 Direct／Final 分析含义与原有来源分类；限制损失单列，避免把损失当作可相加的资源收益。
- 图标和代表色优先复用现有天界维度、神性维度及对应天神素材。

## 3. 机器分析

同一页的内部选择器只提供已经解锁的机器类型，使用现有语言包中的完整名称。

### 现实机器

- 展示实际现实机器收益计算：永恒点数输入、基础收益、倍率、幂运算、取整、收益上限。
- 区分“本次现实预计收益”和“当前可持有上限”，实际奖励使用的批量现实修正也要注明。
- 被动现实机器生成如需显示，单独标明每实际秒收益，不与一次现实奖励混合。

### 虚幻机器与重构机器

- 展示实际容量公式、已记录容量、当前有效容量，以及升级与神性效果带来的修正。
- 按用户补充，IM 与 JM 分析容量上限（cap），展示当前有效容量和当前进度的预计容量。
- 当前容量由历史最高基础容量、容量升级与硬上限组成；预计容量另行展开完整来源。
- 历史记录与当前公式结果不同的情况明确说明，不把当前公式来源当作历史记录的来源。

实现时直接沿用对应游戏页面的可见条件。例如虚幻机器页面还接受终局进度，不能仅复制 `MachineHandler.isIMUnlocked` 而漏掉已有解锁分支。

## 4. 现实次数与终局次数

- 分析一次重置增加的次数，当前累计次数只作上下文显示。
- 现实次数沿用实际奖励流程，包含适用的批量现实与特殊奖励。随机奖励显示概率、期望或范围，分析页本身不能抽取随机数或改变游戏状态。
- 终局次数沿用实际奖励顺序：Enslaved 扩展包与超立方体效果、Alpha 阶段、首次神性里程碑、神性维度转换等。
- 现实次数保持现有 Decimal 类型；终局次数保持现有 Number 类型。分析展示不改变存档数值类型。
- 若需要抽出共享计算方法，重置奖励和分析页共同调用，避免两份公式产生差异。

## 5. 翻译与兼容

- 新增内容同时补齐英文与中文语言包，使用稳定的语义键和完整句子模板。
- 数值、单位、维度层级与资源名称通过参数传入，避免翻译后的短句再拼接英文。
- 延用现有术语，不修改旧键的含义来修复新页面文本；新增匹配规则限定在对应组件内。
- 覆盖页签、来源名称、展开详情、提示、未解锁、禁用、上限和零收益等状态。
- 不更改语言包结构、现有导航编号或已有存档字段。
