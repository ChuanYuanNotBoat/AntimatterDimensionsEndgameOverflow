# 分析页扩展与 Slabdrill 边界修复

日期：2026-10-08

## 已实现

- 维度分类新增天界维度（编号 12）和神性维度（编号 13），按游戏解锁条件显示，支持整体与单层、倍率与指数、直接与最终影响、详情展开。
- 重置分类新增机器（编号 14），在同页切换现实机器、虚幻机器与重构机器。IM／JM 显示容量上限，分别分析当前有效容量与当前进度的预计容量。
- 现实机器分析包含基础奖励、倍率、指数、取整、奖励上限、批量现实及剩余容量限制。被动生成单独说明。
- 重置分类新增现实次数（编号 15）与终局次数（编号 16）。随机额外现实显示期望与范围；查看分析不会抽取随机数、消耗存储时间或更改玩家进度。
- 原编号 0–11、语言包结构和存档字段保持兼容。新增页签、来源、详情说明和状态文本同时提供英文与中文。

## 修复

1. C4／IC1 的诅咒维度购买回调拼错反物质货币名称，导致关闭连续统后手动购买或自动购买崩溃。现在调用正确的货币重置，保留成就决定的起始反物质。
2. 旧的 Slabdrill 离场混合状态保留全局禁用标志。加载时修复已完成离场且没有其他有效天神／虚无运行的情况，保留阶段、资源和第九维购买记录。
3. 离场记录残留 Slabdrill 专用的高升级购买次数，普通模式成本增长因子可能变为负数。实际效果按当前模式的购买上限计算，保留原购买记录。
4. Alpha 完成后，RM／IM 的基础容量为零时，上限扩展公式可能执行 0÷0。零基础容量现在直接返回零。
5. IC3 极端时间间隔购买次数、IC8 维度乘积、Alpha 速度与重构机器容量使用有限值运算，避免有效的大数先溢出再污染后续计算。
6. 新分析模块通过延迟读取游戏公式，避免在游戏基础工具初始化前载入天界维度模块。

## 全套旧测试的限制

发布前基线 `85e3ea44c`：494 项，446 通过、48 失败。当前完整运行：507 项，460 通过、47 失败。
