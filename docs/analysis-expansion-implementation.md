# 分析页扩展与 Slabdrill 边界修复

日期：2026-10-08

## 已实现

- 维度分类新增天界维度（编号 12）和神性维度（编号 13），按游戏解锁条件显示，支持整体与单层、倍率与指数、直接与最终影响、详情展开。
- 重置分类新增机器（编号 14），在同页切换现实机器、虚幻机器与重构机器。IM／JM 只分析当前公式的容量上限；已按后续要求移除历史最高容量分析面板。
- 现实机器分析包含基础奖励、倍率、指数、取整、奖励上限、批量现实及剩余容量限制。被动生成单独说明。
- 重置分类新增现实次数（编号 15）与终局次数（编号 16）。随机额外现实显示期望与范围；查看分析不会抽取随机数、消耗存储时间或更改玩家进度。
- RM 使用单个按钮切换获得量与容量上限分解，始终只显示一个分析面板。
- 系统分类新增热辐射（编号 17）与霍金辐射（编号 18），与 DT 并列，仅在时间压缩解锁后显示。热辐射按实际秒分析；霍金辐射按退出压缩的实际奖励输入、倍率与已有数量扣除分析。
- 地狱 AD 分析下方新增混沌核心搜寻概率分解，复用可展开控件和渊蛇颜色；非地狱不显示。因子与实际搜寻共用公式，不抽取随机数。
- 分解下方显示“获得下一个核心的期望时间”，按当前搜寻间隔除以实际概率计算。明确假设条件固定、每次冷却结束就搜寻；概率为零时显示无限。
- 期望时间以时:分:秒显示，超过一天追加天数，标题与时间分行居中显示；最终概率固定保留五位小数。
- 原编号 0–11、语言包结构和存档字段保持兼容。新增页签、来源、详情说明和状态文本同时提供英文与中文。

## 修复

1. C4／IC1 的诅咒维度购买回调拼错反物质货币名称，导致关闭连续统后手动购买或自动购买崩溃。现在调用正确的货币重置，保留成就决定的起始反物质。
2. 旧的 Slabdrill 离场混合状态保留全局禁用标志。加载时修复已完成离场且没有其他有效天神／虚无运行的情况，保留阶段、资源和第九维购买记录。
3. 离场记录残留 Slabdrill 专用的高升级购买次数，普通模式成本增长因子可能变为负数。实际效果按当前模式的购买上限计算，保留原购买记录。
4. Alpha 完成后，RM／IM 的基础容量为零时，上限扩展公式可能执行 0÷0。零基础容量现在直接返回零。
5. IC3 极端时间间隔购买次数、IC8 维度乘积、Alpha 速度与重构机器容量使用有限值运算，避免有效的大数先溢出再污染后续计算。
6. 新分析模块通过延迟读取游戏公式，避免在游戏基础工具初始化前载入天界维度模块。
7. 每个加成条目保留实际倍率或指数，说明文字作为补充。混合来源类别使用其原始倍率与分层指数，避免重复显示箭头和等效倍率。
8. 子来源实际生效时才显示展开按钮；整体视图同时接受倍率、指数和公式输入。信息按钮仍可查看单个步骤详情。
9. 公式输入为左侧条提供基础贡献。零容量不作为 −100% 削弱；图标直接渲染原版符号，不通过文本翻译替换 iM／jM 等标记。
10. 符文先翻译完整模板，再插入着色数值；名称、稀有度、献祭、提炼及实际上限文本使用完整语言包消息。补齐挑战、打破无限弹窗、时间间隔状态与来源等翻译。
11. 卸载或禁用后立即隐藏中性符文来源；原始倍率／指数为 1 时忽略计算残差，避免 ×1 闪烁。
12. 永恒按钮在所有提前返回前刷新超五立方体可购买状态，避免切档残留。
13. 无限点数分析共用实际倍率累乘顺序，避免先将基础收益乘入各步造成一单位取整差异。
14. 诅咒符文与辐射的有效大数因子在每步限制表示范围；零等级符文不执行阈值倒数的除零运算。

## 全套旧测试的限制

发布前基线 `85e3ea44c`：494 项，446 通过、48 失败。当前完整运行：517 项，470 通过、47 失败。

剩余失败与既有测试清单一致，主要涉及过期的脚本截取／模块模拟、缺失的 Decimal 模拟方法，以及绑定旧实现文本的断言。它们不属于本次新增回归；本次直接涉及的测试装配已同步更新。全套测试尚未全部通过，不据此宣称全套验收成功。

浏览器验收脚本：`scripts/test-expansion-analysis-browser.cjs`。默认连接本机开发服务器，通过环境变量 `ADE_TEST_URL` 可指定地址；`ADE_BAD_SAVE_PATH` 可提供本机损坏存档进行导入回归。每个场景使用独立浏览器上下文并禁用写入存档与备份。

界面与切档回归脚本：`scripts/test-review-ui-browser.cjs`，同样支持 `ADE_TEST_URL`，使用隔离浏览器环境。
